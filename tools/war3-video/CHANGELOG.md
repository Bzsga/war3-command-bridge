# 更新记录

## 1.1.2 — 2026-10-09

备注改为“从未使用过任何外置包的作者/玩家可能需要安装注册表”。“安装注册表”为可点击链接，先提示确认，再打开 Windows 注册表导入窗口；注册表内嵌，取消不导入。


## 1.1.1 — 2026-10-09

附带“启用魔兽本地文件读取.reg”，说明与界面注明部分客户端/地图按需导入并重启；工具不自动修改注册表。


## 1.1.0 — 2026-10-09

快速创建页：选目录、导入视频、自定义 MIX 名称、直接生成到根目录，默认安装触发器动作。目录检测允许提示后继续。旧包可更新或替换并停用备份，避免多个视频包并存；安装失败保留 MIX 并可单独重试。简化作者/玩家说明，保留已有包管理入口。


## 1.0.0 — 2026-10-09

首个编号版本，MIX 管理、触发器安装/卸载、指定玩家控制与 ESC 修复。
