# 更新记录

## 1.0.0 — 2026-10-09

首个带版本号的发行版，整合此前开发成果：

- 单文件 MIX 携带原生启动器、播放器与 MP4；流式导入导出、原子保存、刷新保留视频。
- 六个视频触发器动作，支持指定玩家播放/停止、音量、速率与自动时长。
- 按游戏进程隔离播放器、请求与窗口，处理缓存并发和游戏退出音频。
- 一键为 KKWE/YDWE 安装或卸载触发器动作，保留其他配置、失败回滚。
- 简短作者/玩家说明、作者及 GPT-6 制作声明、GitHub 源码入口。
- 修复全局 ESC 监听导致指定停止时其他窗口也被跳过的问题，取消隐式 ESC 停止。
- 修复原生启动器在编辑器进程中误启用；保存卡住的完整因果与复测尚未确认。

窗口标题、程序集、文件与产品版本同步。版本更新入口：src/AppVersion.cs。
