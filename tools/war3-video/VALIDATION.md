# 验证范围

证据为本机开发记录的公开摘要，未上传用户地图、素材、进程路径或原始私人日志。

| 范围 | 证据 | 边界 |
|---|---|---|
| GUI 定义与注入 | 六个动作经 KKWE 解析、Wave/JASSHelper/PJASS 检查 | 编译不等于所有平台运行 |
| MIX 管理 | 导入导出字节一致、视频保留、重复名及截断拒绝 | 不负责转码 |
| 冷缓存 | 实际游戏重建播放器、请求与视频缓存并输出音视频 | 单机前台检查 |
| 两个真实客户端 | 同机同一 LAN 局，分别解码并输出音频；指定停止、重播、停止全部独立生效 | 双方装插件、窗口化；为 ESC 修复前历史基线 |
| 最新 ESC 修复 | 移除全局键盘停止；两个原生窗口夹具加载真实 MIX，指定停止一端后另一端音频继续 | 此次未新开 LAN 局 |
| 游戏退出 | 真实 WPF 媒体及短寿命窗口/进程，父进程存活时音频停止 | 夹具证据 |
| 编辑器隔离 | 相同 MIX 在 editor/game 命名夹具中分别跳过或启用 | 未验证用户地图保存卡住完全消失 |
| 安装与卸载 | KKWE 实际安装校验；KKWE/YDWE 布局夹具覆盖配置保留、BOM、重复操作、重装与占用失败回滚 | 未启动真实 YDWE |
| v1.0.0 构建 | 管理器与播放器 FileVersion 1.0.0.0 / ProductVersion 1.0.0；正常及最小窗口文字完整 | 版本元数据与布局改动未重复游戏测试 |

历史 LAN 报告是在辅助测试 DLL 清理占用失败后，由已保存日志、音频与 host 数据重建，不能描述为整个测试驱动无异常。

未覆盖：独占全屏、KK 平台、新版/Reforged、跨机器、安装/未安装插件混装。迁移到新机器或编辑器后需建立自己的代表性验证。
